## Re-running

- `pnpm db:seed` — runs catalog seed (drugs, ICD-10) then dev fixtures.
- `pnpm db:reset` — wipes the database, re-applies all migrations, then re-seeds.
- The `demo` tenant is fully cascaded on each run; `platform_admins` rows are upserted (preserved across re-runs, password reset to default).
